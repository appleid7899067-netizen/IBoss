# CodingFleet-style coding tools

For each task, do the work directly with opencode's own tools.

## Tools

- Code Generator: write code from a plain-language description in any language (be specific, English preferred)
- Code Assistant: fix bugs, improve code, answer questions, add features
- Code Explainer: explain unfamiliar code, with adjustable verbosity
- Code Enhancer: list improvement suggestions, then implement the chosen ones
- Code Converter: convert code between languages or frameworks (e.g. Python to Go, Django to Laravel)
- Documentation Generator: docstrings, comments, README, API docs for whole projects
- Comment Generator: add comments and docstrings, with chosen verbosity
- Unit Test Generator: create test cases for existing code
- Code Reviewer: find bugs and security issues
- Code Runner: run code and show results
- Diagram Generator: produce diagrams from code (generate code, run it, output the image)
- Diagram to Code: turn diagrams into working code
- Chat: open-ended coding help with web access, code execution, memory, and parallel agents
